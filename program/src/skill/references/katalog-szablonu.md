# Katalog slajdów szablonu: co do czego

Krótki szablon dla ludzi ma 7 slajdów (oznaczone ★); program i AI korzystają z pełnego katalogu. Źródło: `assets/katalog-szablonu.json` (65 slajdów szablonu `make_template.py`). Ten plik generuje `scripts/katalog_md.py` - nie edytuj go ręcznie, zmieniaj JSON i uruchom skrypt. Agent: najpierw tabela 1 (kształt treści -> slajd), potem tabela 2 (czy slajd naprawdę pasuje: „użyj gdy”, „nie gdy”, „mieści”). Nie wymyślaj własnego układu, gdy któryś slajd pasuje. `tNN` = numer slajdu w szablonie. Reguły R / S: `konwersja-pptx.md` (2a, 2b).

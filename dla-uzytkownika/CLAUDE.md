# Claude Code — start tutaj

Przeczytaj `AGENTS.md` w tym folderze i postępuj dokładnie według niego (program `pliki programu\stworz-cli.exe`,
potem obejrzyj zrzuty, uzupełnij `[nawiasy]`, uruchom kontrolę, oddaj przy `Tekst - problemy: 0`).

Jeśli masz skill `/prezentacje` (`~/.claude/skills/prezentacje`), to ten sam silnik — możesz go użyć do dopracowania
treści (`references/lekcje.md` = decyzje zespołu, `references/spec-dk.md` = format układu slajdów).
